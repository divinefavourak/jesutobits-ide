Install Jesutobits on Linux

An AI agent that builds in front of you. Version @@VERSION@@, for 64-bit Intel and AMD (x86_64).

One command

Adds the Jesutobits repository and installs it on Ubuntu, Debian, Fedora, RHEL relatives and openSUSE. Updates then come with the rest of your system.

curl -fsSL @@PAGES@@/install.sh | sudo sh

Or set it up by hand

Ubuntu, Debian:

curl -fsSL @@PAGES@@/jesutobits.gpg | sudo tee /usr/share/keyrings/jesutobits.gpg > /dev/null
printf 'Types: deb\nURIs: @@APT@@\nSuites: /\nSigned-By: /usr/share/keyrings/jesutobits.gpg\n' | sudo tee /etc/apt/sources.list.d/jesutobits.sources
sudo apt update
sudo apt install jesutobits

Fedora, RHEL relatives:

sudo curl -fsSL @@PAGES@@/rpm/jesutobits.repo -o /etc/yum.repos.d/jesutobits.repo
sudo dnf install jesutobits

openSUSE:

sudo zypper addrepo --refresh @@PAGES@@/rpm/jesutobits.repo
sudo zypper install jesutobits
